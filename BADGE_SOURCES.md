# Badge attribution

These badges are original, unmodified assets from [ziadOUA/m3-Markdown-Badges](https://github.com/ziadOUA/m3-Markdown-Badges), commit `29705300704be2b69814950d721c47a617e467f8`.

All selected assets use the pastel third variant (`*3.svg`). Original vector paths, icons, text, colors and dimensions are preserved. Local filenames are shortened for the profile. Telegram appears both in the tools list and as a contact link.

The upstream project is licensed under GNU GPL version 3. A verbatim copy is provided at `licenses/m3-Markdown-Badges-GPL-3.0.txt`. Original source paths for each asset are recorded in `assets/badges/sources.json`; full editable SVG source is included locally.

There is no DeepSeek badge in the selected upstream catalog. DeepSeek API is named in ordinary text instead of presenting a custom badge as an upstream asset.
